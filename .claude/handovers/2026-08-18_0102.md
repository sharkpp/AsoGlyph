## 決定事項

- **濁音は 25 字を直接書かせる。** 濁点を足しただけの字ではなく、その子が書いた
  1 つの字として残す。合成すると濁点の置き場所という「その子の字ではない情報」が
  フォントに混ざる。収集は 81 字（すうじ 10・ひらがな 46・だくおん 25）
- **なぞり書きも素材にできる。** ライセンス上の懸念は取り下げた。
  最判平成12年9月7日（ゴナU書体事件）により、書体そのものは原則として著作物に
  あたらず、なぞった字形に KanjiVG の著作権は及ばないと考えられる。
  CC BY-SA は著作権を土台にしたライセンスで、及ぶ権利が無ければ条件も働かない
- **ただし「未収集文字を KanjiVG の字形で埋めない」は維持。** こちらは字形の保護では
  なく KanjiVG の**データを複製して出力へ埋め込む**行為で、話が別。SPEC 6.3 に明記した
- **履歴は 1 本のまま、引き方を分ける。** `latestId(char, includeTraced:)`。
  なぞりだけ別テーブルにしても、出力のたびに突き合わせるので得がない
- **既定は「なぞりを混ぜない」。** 充足率と星も「なぞり以外で書けた字」を数え、
  なぞった字は別の印（筆マーク）で見せる。混ぜるかを選べる以上、どちらの字が
  どれだけあるかが一覧で分かる必要がある
- **`PracticeMode.isFontMaterial` は削除。** 素材かどうかは字の性質ではなく、
  出力のたびに決まる
- **矢印は書き終わりではなく書き始めに置く。** 0 は始点と終点が重なるので、
  終わりに矢印を立てても左回りか右回りか決まらない
- **矢印の向きは接線ではなく「書き出しの流れ」。** あ の 3 画目は出だしだけ下へ
  向かってから左へ払うので、接線を取ると向きを読み違える
- **番号の位置は、書き始めのまわりを一周して最良を選ぶ。** 「どの画からも遠い」
  「書き始めの手前」「字の外側」「他の番号から離れる」を足した点数で決める。
  向きを決め打ちすると別の画の上に乗る（あ の 3 画目は 1 画目の横棒に乗っていた）
- **全消しは「このアプリについて」の奥。** SPEC 4.1（削除しない）の明示的な例外。
  取り消せないので確認を挟み、子供の手が届かない場所に置く

## ハマりどころ

- **`Tangent.angle` は y を反転した角度（`-atan2(dy, dx)`）を返す。**
  これに気づかず使い、矢印の上下が逆になっていた。横向きの画では気づけない。
  → `Tangent.vector` を直接使う
- **`late final` の初期化で自分自身を参照できない。** 番号を順に決める処理を
  `late final List<Offset> _anchors = [for (...) _chooseAnchor(i)]` と書き、
  `_chooseAnchor` の中で `_anchors[i]` を読んでいた。即時実行の関数に変えた
- **ディスクが満杯になり、Flutter の debug web ビルドが起動できなかった。**
  真っ白な画面しか出ず、原因が見えるまで時間を溶かした。空きは 410 MB だった。
  → `df` すら出力ファイルを作れず失敗する。ENOSPC が出たらまず容量を疑う
- **`flutter run -d web-server` の debug ビルドは重い。** リリースを
  `python3 -m http.server` で配るほうが速く、確認には十分
- **ウィジェットテストの環境ではフォントが全部 □ になる。** 番号の位置は確認できるが、
  数字そのものはブラウザでしか見えない
- **`RenderRepaintBoundary.toImage` を使うテストは 5 分以上かかることがある。**
  一覧を書き出す用途では実用に耐えるが、常設のテストには置かない

## 学び

- **目で見ないと絶対に見つからない不具合がある。** ヒゲも、保存の取りこぼしも、
  文字の見切れも、テストは全部通っていた。ブラウザで 1 回動かして 3 件出た
- **Playwright（playwright-core ＋ インストール済み Chrome）で Flutter web を
  操作できる。** Flutter は canvas に描くので DOM セレクタは使えず、座標で叩いて
  スクリーンショットを読む。それで十分に用は足りる
- KanjiVG の `kvg:type`（画の種別）は**事実上漢字専用**。実測で、漢字 100%、
  ひらがな・数字・ラテン 0%、カタカナ 2%（マ のみ）
- KanjiVG の中心線からは はね を判別できない。「し」は教科書体では はね だが
  末尾の向きの変化は 3°、一方「な」の結びは 119° で誤検出する
