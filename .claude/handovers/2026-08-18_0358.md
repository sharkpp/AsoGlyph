## 決定事項

### L2 の仕上げ

- **一覧は 2 段**（文字種 → 字）。171 字を 1 枚に積むと子供が自分の字を探せない
- **濁音・小書きは清音と同じ束に入れる。** 子供にとっては同じ「ひらがな」
- **小書きは枠を小さくして書かせる。** 出力時に縮小する案は採らない。
  なぞり書きでは KanjiVG のお手本（すでに 0.8 倍）をなぞるため二重に縮む。
  0.81 はヒラギノ角ゴ W3 と KanjiVG の実測が一致した値

### L3

- **`Policy` は `latest` と `at` だけ入れる。** SPEC の `best` はスコアを見るが、
  スコアは L4。母集団が無いうちに器だけ作らない
- **`charRules` はなぞりを混ぜるかの設定に左右されない。** 親が名指しで選んでいる。
  指す先が消えていたら下位の規則へ落とす
- **版は変えたその場で保存する。**「保存」ボタンは置かない。押し忘れで消える導線を作らない
- **版を消しても Sample は消えない。** 版は導出ビューでしかないので、画面でもそう断る
- **記録も版も同じ 1 つのデータベース。** `SampleStore.open` は `Database` を受け取る形にした
- **版の日付は「その日いっぱい」を含める。** 日付で選ばせて時刻で切ると直感に反する
- **差し替えの一覧は、書いた線をそのまま見せる**（輪郭ではなく）。どの版かは
  日付だけでは決まらない。同じ日に何度も書くので時刻も添える
- **パスコードが守るのは秘密ではなく「子供が入らないこと」。** 集めた字はここで
  守られていないし、端末内で完結する以上その必要もない
- **忘れたときは集めた字を人質にしない。** 掛け算を 1 問挟んで外すだけ。
  子供向けカテゴリで使われている作り。4〜6 歳には解けない
- **パスコードは空で決めると外れる。** 掛けるのをやめる導線をそこに寄せた
- **`SecretStore` を挟む。** テストでプラットフォームチャネルを使わないため（`Speaker` と同じ形）

## 捨てた選択肢と理由

- **小書きを出力時に縮小する** … なぞりで二重に縮む。書いたものと出る字形も一致しなくなる
- **小書きを別の `CharSet` にする** … 濁音と同じ理由。束が分かれると子供が混乱する
- **`best` ポリシーを先に器だけ作る** … スコアが無いので判定できない。L4 で入れる
- **版に「保存」ボタンを置く** … 押し忘れで版が消える
- **パスコードを忘れたら版ごと消す** … 集めた字を人質にする作りになる
- **タイルを 5 列固定のグリッド** … 狭い端末で溢れる

## ハマりどころ

- **プラグインを足したあとの web ビルドは `flutter clean` が要る。**
  `flutter_secure_storage` を足したら `MissingPluginException` で**真っ白**になった。
  `.dart_tool` の web plugin registrant は正しく生成されていたのに、
  ビルド済みバンドルに入っていなかった。**clean 一発で直った**。
  ここに 30 分溶かした
- **ウィジェットテストで sembast を触るときは `runAsync` の外に出さない。**
  `recipes.load()` を外に書いて 10 分固まった（pumpAndSettle の既定タイムアウト）。
  タップが記録を書く場合は、タップと後始末をまとめて `runAsync` に入れ、
  そのあとは `pump()` を使う（`pumpAndSettle()` ではなく）
- **`DateTime` の `==` は UTC と現地時刻を別物として扱う。**
  保存して読み戻した `AtPolicy` が元と等しくならなかった。
  `isAtSameMomentAs` で比べ、`hashCode` は `microsecondsSinceEpoch` から作る
- **`pumpWidget` を 2 回呼んでも State は作り直されない。** 版を差し替えて
  再 pump しても編集画面が古い版のままだった。テストは開く前に状態を作る
- **await していない Future を跨いで finder を使うと "Guarded function conflict"。**
  ダイアログの結果を待つテストは、結果をリストに積んで後から見る形にする
- **日付選択が英語のままだった。** `flutter_localizations` を入れて `ja` に固定
- **AlertDialog に 3 つボタンを並べるとスマホ幅で縦積みになる。**
  「わすれた」は本文側へ移した
