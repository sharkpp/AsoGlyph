## 決定事項

- **絵の大きさはマスいっぱいを 1.0 とする。** 名前の帯を差し引いた残りを 1.0 にすると、
  同じ 1.0 でも名前を出すかどうかで絵の大きさが変わり、「いっぱい」がどこを指すのか
  指定から読めなくなる
- **縮めたぶんの空きは名前の反対側に出す**（名前が下なら絵は上へ寄る）。真ん中に置くと
  空きが上下に割れて、どちらも名前 1 行ぶんに足りない。1.0 なら空きが無いので名前は絵に重なる
- **枠は絵のあとに描く。** 先に描くと、いっぱいに広げた絵が枠線の内側半分を覆う
- **縁を先に、中をあとに描く。線の幅は指定の倍を引く。** 内側の半分はあとから塗る中に隠れ、
  外へ出た半分だけが縁として残る。角は丸める（尖ったままだと縁が角から飛び出す）
- **縁取りはことばだけ。** 単語帳の名前（`--title`）は白い紙の上なので取らない
- **字の大きさは 1 冊につき 1 つ決める。** auto は絵があればマスの高さの 0.14 倍
  （添え書き）、絵が無ければ 0.5 倍（マスはことばのもの）。マスごとに決めると、
  絵のある語と無い語で見出しの大きさが変わる
- **名前は折り返さず、入らなければ縮める。** 折り返すと段の数でマスごとに絵の大きさが変わる
- **紙の余白は既定 0。** 帯の高さもことばと同じ決め方（字の 1.6 倍）に揃えた。
  マスが入りきらない空きは左右で半分ずつ（片側に寄せると、切って使うときに向きで狂う）
- **`[かっこ]`（SPEC 7.4.0）は外して続けて出す。** 紙の上では書く／書かないの区別が要らない
- **字は既定で埋め込まない**（Adobe-Japan1 の `HeiseiKakuGo-W5` を名前で指すだけ）。
  絵で数 MB になる PDF にフォントまで足さない。`--font <ttf>` で埋め込める
- **絵 1 枚で止まらない**（名前と理由を挙げて残りを刷る）。単語帳 1 冊で止まらない
- 単語帳の `author` / `description` は PDF のプロパティに残す（渡った先で出どころが
  分からなくならないように。SPEC 7.4 と同じ理由）
- 名前は `asodict2pdf.py`。README の名前付け（`asodict_<何を>.py`）は `.asodict` に
  手を入れる道具の話で、こちらは読んで別の形にする道具

## 捨てた選択肢と理由

- **PDF を自前で書く**（依存ゼロ）… 日本語には CID フォントの埋め込みか
  Adobe-Japan1 の参照が要る。common functionality の作り直しになる（AGENTS.md）。
  reportlab に寄せた
- **絵を JPEG に焼き直して PDF を小さくする**… 非可逆。親が入れた絵と違うものが出る
  （SPEC 7.4.2 の「縮小はしない」と同じ理由）。可逆な Flate のまま置く
  （ウルトラヒーロー 58 枚で 20MB）
- **絵を刷る大きさに合わせて間引く**… 同じ理由で採らない
- **名前の帯を絵から取り分ける**（最初の実装）… 「マスいっぱい」が指定から読めなく
  なるので捨てた（上の決定事項）
- **`--word-aligin` の綴りも受ける**… 後方互換のための別名は足さない（AGENTS.md）
- **CSV の列に作成者・概要を足す**… SPEC 7.4 で既に否定されている。触っていない
- **`--tag` を複数回書けるようにする**… `,` 区切りの 1 つで足りる

## ハマりどころ

- **PDF の塗り方（`Tr`）は文字の並び（BT/ET）を閉じても残る。** reportlab の
  `PDFTextObject` は自分が 0 のつもりで始まるので、`setTextRenderMode(0)` は
  指図を出さない。結果、縁取りの次の「中を塗る」回が縁のまま描かれ、**字が縁の色で
  塗り潰される**（白い縁なら真っ白な字になる）。縁を引いたら並びの中で 0 に戻す
- **reportlab の `Canvas` に `setTextRenderMode` は無い**（`PDFTextObject` にしか無い）。
  そのため `drawString` ではなく `beginText` を通し、寄せの位置は `stringWidth` から自分で出す
- **縁取りの既定を字の 0.08 倍にしたのは実測。** 最初に置いた値でも見た目は同じだったが、
  それは上の `Tr` の不具合で潰れていただけ。直したあと 0.1/0.2/0.3mm を 400dpi で
  見比べて決めた
- **ヒラギノ（`.ttc`）は埋め込めない**。輪郭が CFF で、reportlab は glyf しか読まない。
  何が駄目かを言って止まるようにした
- **この環境の python3 は PEP 668 で外部管理**（`pip install` が拒まれる）。
  確認は scratchpad の venv で行った。`Pillow` は入っているが `reportlab` は入っていない
- 確認の途中で `assets/words/hiragana.pdf` を書いてしまった（`-o` を付け忘れると
  入力の隣に出る）。消した

## 学び

- 縁取りは **mode 1（縁だけ）→ mode 0（中だけ）の 2 回**で描く。mode 2（塗って縁）だと
  縁の内側半分が字を細らせる。線の幅を倍にするのは、内側半分があとの塗りに隠れるため
- 「いっぱい」のような言葉は**基準をどこに置くかで意味が変わる**。マスを基準にすれば
  指定から読めるが、残りを基準にすると他の指定で動く
- 詰め込みは**余白より用紙の使い方**が効く。A4・40mm で余白 10mm → 0 にするだけで
  1 ページ 24 → 35（＋46%）
