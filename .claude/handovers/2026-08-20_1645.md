## 決定事項

- **URL とパスの大小文字はリポジトリ名（`AsoGlyph`）に揃える。** GitHub Pages のサブパスは
  リポジトリ名がそのまま出る。小文字にしても届かない
- **manifest の `id` は配布先からの相対（`.`）にする。** `"/"` だとオリジン直下を指し、
  `scope: "./"`（= `/AsoGlyph/`）と食い違う。同じオリジンに別のアプリを置いたときに
  同一のアプリと見なされる

## 捨てた選択肢と理由

- **パッケージ名・バンドル ID・拡張子まで `AsoGlyph` に揃える** … 採らない。
  `pubspec.yaml` の `name: asoglyph`、`net.sharkpp.asoglyph`、控えの `.asoglyph`、
  `sw.js` のキャッシュ名は URL とは無関係で、直すと import 全部と既存端末の控えに波及する
- **`.claude/handovers/` の過去のノートの URL も直す** … 採らない。その時点の記録であり、
  あとから書き換えるものではない

## ハマりどころ

## 学び

- **サブパス配布で直すべき場所は `--base-href` だけではない。** manifest の `id` のように
  絶対パスで書いた 1 行が残っていると、そこだけオリジン直下を指し続ける。
  相対で書ける項目は相対で書いておけば、置き場所が変わっても付いてくる
- ワークフローに置いた公開前の検算（`grep -q '<base href="..."'`）が、パスを直したときに
  片方だけ直す取りこぼしを拾う。base-href とセットで直す必要があるので、
  どちらかを忘れると CI が落ちる
