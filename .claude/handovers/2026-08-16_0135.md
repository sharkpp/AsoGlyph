## 決定事項

- **KanjiVG は必要な字だけ抽出する。** 全 6,702 字は 6.4 MB（gz 2.4 MB）。
  収集対象は L5 まで行っても 1,200 字ほどで、使わない字を抱える理由がない。
  いまは 56 字 14 KB。`CharSet` が増えたらスクリプトを流し直せば出力も追随する
- **抽出結果は SVG パス文字列のまま持つ。** 数値へ潰さないのは、KanjiVG の
  原データと目視で突き合わせられるから。CC BY-SA 3.0 の履行に効く
- **パースは `path_parsing`。** flutter_svg が使っているパッケージで、
  2024-11 まで更新がある。`PathProxy` を実装した 15 行のアダプタで `Path` に積む
- **お手本は KanjiVG に置き換えた。** システムフォントは印刷用の字形で、
  手で書く形と違う（さ・き の続け方など）。子供が真似る対象として正しくない
- **モードは書く前に決め、書き取り画面では変えられない。** 一度見てから隠した字は
  「何も見ずに書いた」ではない。記録の意味を濁さない
- **モードの並びは なぞる → おてほん → じぶんで。** 左から難しくなる
- **なぞり書きの下敷きは全画そろえて出す。** 順に伸ばすとなぞる先が見えない
  （枠のお手本のほうは順に引く）
- **読み上げの失敗は握りつぶす。** エンジンの無い Android 端末や
  SpeechSynthesis の無いブラウザがある。音が出なくても字は書けること
- **クレジットは外部リンクにしない。** 子供向けカテゴリは外部リンクの扱いが
  厳しい（SPEC 10）。URL は文字として置き、アプリ内で読み切れる形にした
- **`Speaker` を interface にした。** 本物は端末エンジンを叩くのでテストで使えない。
  テスト用の `RecordingSpeaker` は `test/support/` に置き、lib には本番の実装だけ残す

## 捨てた選択肢と理由

- **KanjiVG を全字同梱** … 6.4 MB。使わない字が 5,500 字。
  CC BY-SA 3.0 で公開する義務があるデータは、小さいほうがレビューもできる
- **抽出時に数値列へ変換して runtime のパーサを無くす** … 変換側に同じパーサが
  要るだけで総量は減らない。原データとの突き合わせができなくなる分だけ損
- **`path_drawing`** … 最終更新 2022 年。中身は `path_parsing` の薄い包み。
  直接 `path_parsing` を使えば済む
- **`getSpeechRateValidRange` で等倍速度を問い合わせる** … web に実装が無く
  例外になる。Android/iOS 0.5・web 1.0 を定数で持つほうが確実
- **書き取り画面に「おてほんを隠す」トグル** … 見てから隠した字を `free` として
  記録することになる。モードの意味が壊れる
- **`SilentSpeaker` を lib に置く** … `TtsSpeaker` が失敗を握りつぶすので本番では
  要らない。使うのはテストだけなので `test/support/` へ

## ハマりどころ

- **`CustomPaint` は `Center` の中だと 0 サイズになる。** 子を持たない `CustomPaint` は
  制約の最小値を取る。`Center` は緩い制約を渡すのでサイズが 0 になり、何も描かれない。
  → `StackFit.expand` の Stack 直下に置いて tight な制約を渡す
- **`tester.pageBack()` が使えない。** 書き取り画面の戻るボタンは tooltip の無い
  `IconButton` で、`pageBack` は tooltip 'Back' か Cupertino の戻るボタンを探す。
  → 画面を往復するテストは書かず、状態ごとにテストを分けた
- **`extractPath(0, 0)` は空の `Path` ではなく起点だけの `Path` を返す。**
  `getBounds()` は `Rect.zero` ではなく起点の縮退矩形になる。`isEmpty` で見ること
- KanjiVG の `d` を正規表現で抜こうとすると `kvg:type` 属性に阻まれる。
  XML パーサ（`xml` パッケージ）を使うこと

## 学び

- KanjiVG の 1 画は必ず単一の輪郭で、命令は `M` と相対 `c` だけ。
  `computeMetrics().single` で受けておくと、漢字を足したときに崩れれば気づける
- KanjiVG main.xml には画数ラベルの座標グループが無い（`-all` のほうにある）。
  必要になったら各画の起点から自前で置ける
- `flutter test` で `rootBundle` から pubspec 宣言済みの asset を読める。
  同梱データそのものをテストできる（56/56 字あるか、座標が viewBox に収まるか）

## 積み残しの気になる点

- **`free` でも一覧のタイルで字が見える。** タイルは 32px でお手本の 180px とは
  比べものにならないが、厳密に「何も見ていない」わけではない。
  塞ぐには「アプリが字を選んで出す」形が要り、それは出題ロジック（L4）
