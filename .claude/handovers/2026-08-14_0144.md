## 決定事項

### 製品

- 主対象は 4歳後半〜6歳（年中〜年長）。3〜4歳は `trace`（なぞり書き）モードで入口のみ提供し、素材としては採用しない
- 子供向け画面は文字に依存しないUI（アイコン＋音声＋イラスト）。L1 から音声の土台を入れる
- 採点は出題の重み付けにのみ使う。フォント採用可否には使わない（例外は鏡文字と明らかな書き損じのみ）。理由: 子供の字の価値は歪みにあるため
- 練習モードは `trace` / `copy` / `free` の3段階。素材として採用するのは後ろ2つ

### データモデル

- **スナップショットは実体を持たせず、解決規則の集合（FontRecipe）として表現する**
  - 解決順は `charRules` > `groupRules` > `base`
  - `base` の既定は `latest`（期間無制限）。時点指定はオプトイン
  - 理由: 文字種ごとに収集開始時期が違う（ひらがな4歳／漢字6歳）ため、単一時点基準だと後発の文字種が空になる
- Sample は不変・追記のみ。座標は正規化 em 空間（0–1000）で保存する（デバイスピクセル保存はフォント破綻の原因）
- 濁音は既定で「清音46字＋゛゜」を収集し出力時に合成。直書きは管理画面で選択可能
- 収集対象と出力対象は別設定にする

### 技術

- Flutter / 端末内完結（サーバーへ筆跡を送らない）
- 輪郭化は **ラスタトレース方式**（PictureRecorder → 1024px → marching squares → RDP → ベジェフィット）
- OTF は fontify（MIT / 純Dart）を流用。**TTF ライタは自作**
- レイアウトは `LayoutBuilder` ＋ shortestSide 600dp をブレークポイント

### ライセンス

- KanjiVG（CC BY-SA 3.0 / Ulrich Apel）を採用
- **未収集文字を KanjiVG の字形で埋めない**ことを設計上の不変条件とする（埋めるとフォントが二次的著作物になり SA 感染する）
- 学年別漢字配当表は事実データとして自前保持（KANJIDIC2 を持ち込まない）

## 捨てた選択肢と理由

- **文字単位で版を選ぶUI** — 親が50字を1つずつ選ぶのは苦行。ただし `charRules` として「特定文字だけ古い版」は残した
- **容量を理由にした履歴削減** — 試算した結果、1文字約0.9KB、46字×200回で約8MB。容量は問題にならない。スナップショット方式を採る理由は容量ではなく UX
- **clipper2（Dart のブーリアン演算）** — v0.0.3・更新停滞・web で64bit整数制約。依存先として弱い
- **Flutter 標準 `Path.combine(union)`** — 堅牢だが `dart:ui` の Path はベジェ命令を読み出せず、結局サンプリング＋再フィットが必要になる
- **opentype.js** — 初回提案時に挙げたが、Flutter 採用決定により不適
- **KANJIDIC2 による学年情報** — 依存ライセンスが増える。配当表は事実データなので自前で持てる
- **全ユーザー横断の難易度統計** — サーバーが必要になり要件が跳ね上がる。母集団は本人の履歴のみ
- **端末へのフォント直接インストール** — iOS は構成プロファイル必須、Android は非 root で不可。出口はファイル共有とする
- **3〜4歳を主対象にする** — 字が書けずフォントが完成しない。ただし完全に切り捨てると最も価値ある年齢の筆跡を逃すため、モードの分岐で吸収した

## ハマりどころ

- GitHub contents API 経由で KanjiVG のファイル一覧を確認したところ、`030a1.svg` / `030fc.svg` が「存在しない」と返ってきた。実際には raw URL への直接アクセスで全て 200。**巨大なディレクトリ一覧の読み取りは信用せず、raw への HTTP ステータスで確認すべき**
- fontify 系パッケージは「SVG → フォント生成」と紹介されるが、実際は **OTF 出力のみで TTF は未実装**（README のロードマップ止まり）。要件の TTF/OTF 両対応には自作が必要という結論に直結した

## 学び

- KanjiVG は漢字だけでなく **数字・ラテン大文字小文字・濁音半濁音・小書きかな・長音符・句読点まで収録**している。「」と ？ は無い
- KanjiVG の viewBox は `0 0 109 109`。em 1000 への正規化は 1000/109 倍
- 濁音字は「清音の画＋濁点の画」の連続として1ファイルに入っている（が = 5画 = か3画 + 濁点2画）。濁点の配置基準として利用できる
- ラスタトレース方式には「練習画面で子供が見た線とフォントの字形が完全に一致する」という副次的利点がある。この製品では特に価値が高い
- ベネッセ調査でかな文字が読める割合は年少 66.8% / 年中 88.1% / 年長 97.2%。図形模写は円3歳・十字4歳・四角5歳・三角5〜6歳・ひし形6〜7歳。斜線と方向転換の獲得が5歳前後で、ひらがなが書けるかの境界になる
