# 単語帳を作る道具（SPEC 7.4）

単語帳にまつわる道具はここにまとめる。単語帳の出どころは増える見込みなので、
**名前の付け方を先に決めておく**。

| 名前 | 何をするか |
|---|---|
| `pack.dart` | フォルダ（YAML ＋ 絵）を `.asodict` にまとめる。出どころによらず、最後は必ずここを通る |
| `<出どころ>_<何を>.py` / `.dart` | どこかから語を集めて、単語帳のフォルダを書く |

出どころを頭に置く（`m78_character.py`）。同じ site から別のものを集める道具が
増えても並びで分かるし、`build_` のような、全部に付いて何も区別しない語を
足さずに済む。

## 集めてから、まとめる

集める道具は**フォルダ（YAML ＋ 絵）まで**を書き、`.asodict` にするのは
`pack.dart` に渡す。分けているのは、

- `.asodict` の作り方（zip の組み方・YAML の引用符・絵の上限）を 1 か所に置くため。
  `pack.dart` は `lib/word/` をそのまま呼ぶので、アプリと必ず同じものが出る
- 集めたあとに手を入れられるようにするため。取ってきた読みが直せないと、
  読み上げが直せない

集める道具は最後に `pack.dart` を呼ぶので、ふだんは 1 回叩けば `.asodict` まで出る。

## いま入っているもの

### `m78_character.py` — m-78.jp のキャラクター一覧

```
python3 tool/word_book/m78_character.py https://m-78.jp/character/category/261/
  → work/ウルトラヒーロー/              （YAML ＋ 絵）
  → assets/words/_ウルトラヒーロー.asodict
```

一覧をたどって、名前とサムネイルを集める。**URL は 1 つも書いていない。**
出発点は引数で受け、次のページも絵の場所もページに書いてあるものをたどる。
単語帳の名前もページの見出しから引くので、一覧の URL を変えれば
そのカテゴリの単語帳がそのまま作れる（ウルトラ怪獣・防衛チームなど）。

Pillow が要る（`pip install Pillow`）。落とした PNG・JPEG を WebP に焼き直すため。
元のままだと 58 枚で 14 MB になり、資産に入れるには大きすぎる。

読みに落とせない字（漢字など）が残った語は入れずに、名前を挙げて知らせる。
「ウルトラの母」のように読みを人が決めるしかない語は、書き出した YAML に
手で足して `pack.dart` を掛け直す。

### `pack.dart` — フォルダを `.asodict` にする

```
dart run tool/word_book/pack.dart <フォルダ> [出力先]
```

出力先を省くと `assets/words/_<フォルダ名>.asodict`。`_` で始まるので
デバッグでだけ読み込まれ、リポジトリにも入らない（SPEC 7.4.3）。
配るものにするときは、出力先を `_` の付かない名前で指定する。
