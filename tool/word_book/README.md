# 単語帳を作る道具（SPEC 7.4）

単語帳にまつわる道具はここにまとめる。単語帳の出どころは増える見込みなので、
**名前の付け方を先に決めておく**。

| 名前 | 何をするか |
|---|---|
| `pack.dart` | フォルダ（YAML ＋ 絵）を `.asodict` にまとめる。出どころによらず、最後は必ずここを通る |
| `word_text.py` | 語の字づかい（読み・置き換えの表・YAML のスカラ）。集める道具と直す道具で分け合う |
| `asodict_<何を>.py` | できあがった `.asodict` に手を入れる |
| `<出どころ>_<何を>.py` / `.dart` | どこかから語を集めて、単語帳のフォルダを書く |

出どころを頭に置く（`m78_character.py`）。同じ site から別のものを集める道具が
増えても並びで分かるし、`build_` のような、全部に付いて何も区別しない語を
足さずに済む。

## 集めてから、まとめる

集める道具は**フォルダ（YAML ＋ 絵）まで**を書き、`.asodict` にするのは
`pack.dart` に渡す。分けているのは、

- `.asodict` の作り方（zip の組み方・YAML の引用符・絵の上限）を 1 か所に置くため。
  `pack.dart` は `lib/word/` をそのまま呼ぶので、アプリと必ず同じものが出る
- 集めたあとに手を入れられるようにするため。取ってきた読みが直せないと、
  読み上げが直せない

集める道具は最後に `pack.dart` を呼ぶので、ふだんは 1 回叩けば `.asodict` まで出る。

## 漢字は集めたまま持ち、あとから開く

ページに載っている名前には漢字が混ざる（「深海怪獣 ピーター」）。子供が書くのは
かなだけなので（SPEC 5）、どこかで かなに開かないと出題から丸ごと外れる
（SPEC 7.4.2）。開き方は 1 か所——**置き換えの表**だけが決める。

```toml
"深海怪獣" = "しんかいかいじゅう"
```

集める道具は名前を漢字のまま持ち、表は「読みがまだ書かれていない」形で書き出す。
読みを書いてから `asodict_rename_words.py` を掛けると、ことばも読みも
かなに開く。集めたものと直したものが別れているので、**読みを直すのに
364 枚の絵を取り直さなくてよい**。

## いま入っているもの

### `m78_character.py` — m-78.jp のキャラクター一覧

```
python3 tool/word_book/m78_character.py https://m-78.jp/character/category/626/ \
    --kanji tool/word_book/ultra_monster_kanji2hira.toml
  → work/ウルトラ怪獣/ウルトラ怪獣(ウルトラQ)/    （YAML ＋ 絵）
  → assets/words/_ウルトラ怪獣(ウルトラQ).asodict
  → …作品の数だけ
```

一覧をたどって、名前とサムネイルを集める。**URL は 1 つも書いていない。**
出発点は引数で受け、次のページも絵の場所もページに書いてあるものをたどる。
単語帳の名前もページの見出しから引くので、一覧の URL を変えれば
そのカテゴリの単語帳がそのまま作れる（ウルトラヒーロー・防衛チームなど）。

**作品ごとに 1 冊にする。** ウルトラ怪獣は 364 体あり、1 冊にすると子供の
一覧が延々と続く。作品ごとなら「うちの子はウルトラマンだけ」という割り振り
（`User.wordBooks`）ができる。作品の見出しはページをまたいで続くので、
見出しの無いまま始まるページは前のページの作品に続ける。

作品の見出しが 1 つも無い一覧（ウルトラヒーロー）は割りようがないので、
1 冊にまとめてカテゴリ名でそのまま呼ぶ。

| 選択肢 | |
|---|---|
| `--until <名前>` | その名前のカードまでで打ち切る |
| `--kanji <表.toml>` | 漢字をかなに開く表。既定は `<出力先>/kanji2hira.toml` |

表はすでにあれば**読みを残したまま**書き直すので、掛け直しても書いた読みは
消えない。表に読みが無くて読みが起こせない語（「異次元列車」のように漢字だけの
名前）は入れずに、名前を挙げて知らせる。読みを書いて、もう一度掛ければ入る。

すでに落としてある絵は取り直さない。表に読みを足して掛け直すのがふつうの
使い方で、そのたびに全部を落とし直すのは重い。取り直したいときはフォルダごと消す。

Pillow が要る（`pip install Pillow`）。落とした PNG・JPEG を WebP に焼き直すため。
元のままだと 364 枚で 90 MB を超え、資産に入れるには大きすぎる。

### `asodict_rename_words.py` — 名前をかなに開く

```
python3 tool/word_book/asodict_rename_words.py \
    tool/word_book/ultra_monster_kanji2hira.toml assets/words/_ウルトラ怪獣*.asodict
```

`.asodict` を開いて `words.yaml` だけを書き替え、また閉じる（元のファイルに
上書きする）。絵はそのまま入れ直す。

- **読みはことばから起こし直す。** ことばを直したのに読みが元のままだと、
  画面に出ている字と声が食い違う
- **値を空にすると消える。** かっこや「・」は名前の区切りに使われていて、
  そのままでは子供が書けない
- 表に無い漢字が残った語は**名前を挙げて知らせる**。黙って通すと、単語帳に
  入っているのに一度も出てこない語になる

### `ultra_monster_kanji2hira.toml` / `ultra_hero_kanji2hira.toml` — 表

`m78_character.py` が書き出し、読みを手で書いたもの。

| 表 | カテゴリ | |
|---|---|---|
| `ultra_monster_kanji2hira.toml` | 626 ウルトラ怪獣 | 364 体 / 270 語 |
| `ultra_hero_kanji2hira.toml` | 261 ウルトラヒーロー | 58 体 / 7 語 |

ヒーローの表が 7 語で済むのは、名前に漢字がほとんど無いため。中身は
「ウルトラの父・母」と、読みが添えてある名前（`A(エース)` `80(エイティ)`
`21(ツーワン)`）のかっこを落とすぶんだけ。**読みが添えてある名前は、
読みのほうを書かせる**（`80` ではなく `エイティ`）。聞こえた音と書く字が
違うと、声を頼りに書く子（`free`、SPEC 7.1）がその 1 語だけ書けない。

### `pack.dart` — フォルダを `.asodict` にする

```
dart run tool/word_book/pack.dart <フォルダ> [出力先]
```

出力先を省くと `assets/words/_<フォルダ名>.asodict`。`_` で始まるので
デバッグでだけ読み込まれ、リポジトリにも入らない（SPEC 7.4.3）。
配るものにするときは、出力先を `_` の付かない名前で指定する。

### `asodict2pdf.py` — 単語帳を紙に敷き詰める

```
python3 tool/word_book/asodict2pdf.py \
    --word-size 40mm --border yes assets/words/_ウルトラヒーロー.asodict
  → assets/words/_ウルトラヒーロー.pdf
```

単語帳は子供が語を選ぶためのもので（SPEC 7.4.2）、その一覧を紙で見たいことが
ある。絵と名前を並べて刷れば、書く前に「どれを書くか」を紙の上で選べる。
かるたにも切れる。

`.asodict` / `.yaml` / フォルダのどれでも渡せる（**集める道具が書くのはフォルダ**
なので、`pack.dart` を通す前でも刷れる）。出す先は入力ごとに `<名前>.pdf`。

**`--merge` で、渡した単語帳ぜんぶを 1 つの PDF にまとめる。**

```
python3 tool/word_book/asodict2pdf.py --merge -o work/ウルトラ怪獣.pdf \
    --word-size 35mm --border yes assets/words/_ウルトラ怪獣*.asodict
```

作品ごとに 1 冊にしてある単語帳（`m78_character.py` は 10 冊書く）を、刷るときだけ
1 つに束ねるためのもの。名前を刷るなら（`--title yes`）**単語帳ごとに紙を変えて**
見出しの下から始め、丁付けは PDF ぜんぶを通して数える。名前を刷らないなら
（`--title no`）**紙を変えずに詰める**——名前の出ない切れ目で紙を変えても、
変わったことが紙の上に何も残らないので、ただ空きが増える。

| 選択肢 | 既定 | |
|---|---|---|
| `--page-size` | `a4` | 用紙。名前（`a3`〜`a6` `b4`〜`b6` `letter` `legal`）か `210mm,297mm` |
| `--landscape` | — | 紙を横にする |
| `--word-size` | `40mm` | マスのサイズ。`40mm,30mm` か 1 辺だけ |
| `--margin` | `0` | 紙の余白。1 つ（上下左右）・2 つ（上下,左右）・4 つ（上,下,左,右） |
| `--gap` / `--padding` | `0` / `1mm` | マスの間／マスの内側 |
| `--title` / `--title-size` | `yes` / `5mm` | 単語帳の名前を刷るか（2 ページ以上なら丁付けも） |
| `--image` / `--image-zoom` | `yes` / `1.0` | 絵を描くか／マスいっぱいを 1.0 とした割合 |
| `--word` / `--word-source` | `yes` / `text` | ことばを描くか／ことばか読みか |
| `--word-align` | `bottom,center` | ことばの位置。`垂直,水平` |
| `--word-wrap` / `--word-wrap-min` | `0` / `0` | ことばを何字で折り返すか（`0` は折らない）／最後の行がこの字数以下なら折るのをやめる |
| `--word-title` / `--word-title-size` | — / `auto` | マスの上端に置く小見出し（`{book}` は単語帳の名前）／字の大きさ（既定はことばの 0.7 倍） |
| `--word-font-size` / `--word-color` | `auto` / `0,0,0` | 字の大きさ（既定は PDF 1 つで 1 つに決める）／色 |
| `--word-outline-width` / `--word-outline-color` | `auto` / `255,255,255` | 縁取りの幅（既定は字の大きさの 0.08 倍。`0` で取らない）／色 |
| `--border` / `--border-color` / `--border-width` | `no` / `0,0,0` / `0.1mm` | マスの枠 |
| `--merge` | — | 渡した単語帳ぜんぶを 1 つの PDF にまとめる（`-o` が要る） |
| `--tag` | — | このタグの語だけを刷る（`,` で複数） |
| `--font` | — | 埋め込む TTF。省くと `HeiseiKakuGo-W5` を名前で指すだけ |

- **紙の余白は既定で 0**（詰められるだけ詰める）。端が切れるプリンタで刷るときは
  `--margin` を足す。`--margin 10mm`（上下左右）・`--margin 5mm,20mm`（上下,左右）・
  `--margin 30mm,5mm,10mm,40mm`（上,下,左,右）。並びは「縦から横へ」で
  `--word-align` の 垂直,水平 と同じ（**CSS の 上,右,下,左 とは違う**）
- **絵はマスいっぱいが `--image-zoom 1.0`。** そこから割合で縮める。
  引き伸ばさない（縦横の比を変えると、親が入れた絵と違うものが出る）
- 縮めたぶんの空きは**名前の反対側**に出す（名前が下なら絵は上へ寄る）。
  1.0 のままなら空きが無いので、名前は絵の上に重なる
- **`--word-title` でマスの上端に 1 行添えられる。** `{book}` はその語が入っていた
  単語帳の名前に替わる。まとめて詰めたとき（`--merge --title no`）は、どの冊から
  来た語なのかが紙の上から消えるので、切ってかるたにするならここに出す。
  ことばを上に寄せているときは、ことばを小見出しの下に置く
- **名前は縁を取ってから中を塗る。** 絵の上に重なるので、縁が無いと絵の濃い
  ところで読めない。白抜きにしたいときは `--word-color 255,255,255
  --word-outline-color 0,0,0`
- 縁の幅を書かなければ、**描く大きさ**の 0.08 倍を使う（`--word-outline-width` で
  書けばその幅のまま）。頼んだ大きさから決めると、幅に入らなくて縮んだ字に太い
  ままの縁が付き、細い画が縁で埋まって字が縁の色の塊になる
- **長い名前は既定で縮める**（1 行のまま小さくする）。`--word-wrap 8` のように
  **字数**を渡すと、その字数で折り返す
  - **折る場所は字数だけで決め、字の大きさは見ない。** 1 行に何字並ぶかがそのまま
    大きさの上限になる（30mm のマスに 8 字なら 1 字 3.7mm まで）。**頼んだ大きさより
    大きくはしない**——「入るいちばん大きい字」を探すと、行数の減りぶんまで
    大きさに回ってマスいっぱいの字になる
  - 空白があればその手前で折る（空白は落とす）。そのぶん行は渡した字数より短くなる
  - **行頭に置かない字**（小書き・長音符・句読点・閉じかっこ）は前の行に連れていく
    ので、行は渡した字数より少し長くなることがある
  - **最後の行が短くなるなら折らない**（`--word-wrap-min 3`）。1〜2 字の行が
    ぶら下がると、そこで語が終わっているように見える
- `[かっこ]`（SPEC 7.4.0）は外して続けて出す。紙の上では書く／書かないの区別が
  要らない
- **絵が 1 枚描けなくても止まらない**。名前と理由を挙げて、残りを刷る。
  読めない単語帳が混ざっていても、残りの冊は刷る
- まとめるとき、**作った人は渡された冊ぜんぶで同じときだけ** PDF に残す。混ざった
  ものを 1 人の名前で出すと、出どころを取り違えたまま渡ることになる（SPEC 7.4）

reportlab が要る（`pip install reportlab`）。SVG の絵を描くには svglib も
（無ければ SVG の絵だけが抜ける。PNG・JPEG・WebP はそのまま描ける）。
既定では字を埋め込まない（Adobe-Japan1 の標準フォントを名前で指す）ので、
日本語フォントの無いところで刷るときは `--font <ttf>` を渡す。
