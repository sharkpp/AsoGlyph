# 内蔵の単語帳（SPEC 7.4）

ここに置いた `.yaml` と `.asodict` は、アプリに入っている単語帳として
起動のたびに読み込まれる。親が取り込まなくても最初からあり、
要る要らないは人ごとのチェックで切り替える。

- **直せない・消せない。** 直したい人は管理画面から「コピーを作る」
- 足すときはこのディレクトリにファイルを置くだけでよい。一覧は資産そのものから
  引くので、コードに書き足す必要はない（`AppBundledAssets.list`）
- 絵を付けるときは `.asodict`（`words.yaml` ＋ `images/` の zip）を置く。
  管理画面の「書き出す」で作ったものがそのまま使える
- `author`（作った人＝著作権者）と `description`（概要）は任意。書けば管理画面の
  一覧と単語帳の画面に出る。人に渡した先でも残る

```yaml
version: 1
name: ひらがなのことば
author: sharkpp
description: ひらがなだけで書ける、身のまわりの語
words:
  - text: ねこ
    reading: ねこ
```

## 直したものを読み込ませる

**ファイルを置き換えて、アプリを開き直すだけ。** 起動のたびに中身を突き合わせ、
変わっていれば入れ替える。人ごとの割り振りも並びも保たれる（同じ id のまま
中身だけ入れ替える）。

| どこで | すること |
|---|---|
| `flutter run` 中 | **ホットリスタート**（`R`）。ホットリロード（`r`）では読み直さない |
| web に置いたもの | 置き換えてから読み込み直す。サービスワーカーは network-first なので、オンラインなら新しいものが来る |
| 端末に入れたもの | アプリを起動し直す |

読めないファイルは、**その 1 冊が出ないだけ**になる（アプリは開く）。
何が悪いかはログに出る。`単語帳を読めませんでした: <パス> (...)`。

### よくある壊し方

`text` に `[` を含む語（`[ウルトラマン]オメガ`）は、**必ず引用符でくくる**。

```yaml
  - text: "[ウルトラマン]オメガ"   # かっこ始まりは YAML の配列に見える
    reading: うるとらまんおめが
```

管理画面から書き出したものは自動で引用符が付く。手で足すときだけ気をつける。

## 動作確認用の辞書

**ファイル名を `_` で始める**と、デバッグ実行でだけ読み込まれる。
`.gitignore` で除いてあるのでコミットもされず、素の取得から作った
リリースには存在しない。

```
assets/words/_ウルトラマン.asodict   ← 手元でだけ出る。管理画面に「動作確認用」と出る
```

置いたら `flutter run` を掛け直す（資産の一覧はビルド時に作られる）。
